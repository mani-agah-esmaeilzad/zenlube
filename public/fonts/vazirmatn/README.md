# Existing Oilbar font assets

These are the exact, unmodified Vazirmatn files previously served by
`https://fonts.bunny.net/css?family=vazirmatn:400,500,600,700,800,900&display=swap`.

Downloaded on 2026-09-12 to remove the render-blocking third-party stylesheet.
All existing weights (400–900), Latin, Latin Extended and Arabic subsets, WOFF2
and WOFF fallbacks, Unicode ranges and `font-display: swap` are preserved.
The CSS family remains `Vazirmatn`; no typography or storefront layout changes.

Vazirmatn project: https://github.com/rastikerdar/vazirmatn
